# M3 編集画面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 作品画面を ④ 編集画面に置き換える。ペン、消しゴム、バケツ、選択（タップ・範囲）と色の変更・削除、縁取り、Undo/Redo（200手）、左右反転、完成イメージ、iPhone のピンチズームとドラッグでの移動、自動保存を実装する（仕様書 §3.2、§6.1、§6.4、§7、§10 M3）。

**Architecture:**
- 編集のロジックはすべて zustand の `editor` ストア（`src/state/editor.ts`）に置く。M1 の `ops`（差分を返す純粋関数）と `History` を使い、Node の Jest でテストする
- 画面の座標とマスの変換、ズームの計算は純粋関数（`src/ui/sheetGeometry.ts`、`src/ui/zoom.ts`）にしてテストする
- 描画は M2 の `paintSheet` に反転と完成イメージのオプションを足し、選択範囲は別の軽い重ね描きにする
- ジェスチャーは M2 の CropBox と同じく React Native の `PanResponder` で扱う。1本指はツールの操作、2本指はズームと移動（iPhone のみ）

**Tech Stack:** M2 と同じ（Expo SDK 58、expo-router、Skia 2.14、zustand 5、Playwright の Web E2E）

**Spec:** `docs/superpowers/specs/2026-11-11-digital-iron-beads-design.md`

## Global Constraints

- M0〜M2 の計画の Global Constraints はすべて引き続き有効（画面ファイルは `src/app/`、スクロールしない、`colors`/`fonts` だけを使う、ボタンは 44pt 以上、`EXPO_OFFLINE=1 npx expo install`）
- **iPad ではシートを動かさない**：ズームも移動もしない（`Platform.OS === 'ios' && Platform.isPad`）。iPad の実寸表示は M4 で作る。M3 では箱に収めて表示する
- Undo の1単位：ペンや消しゴムは「指を置いてから離すまで」、バケツ・縁取り・色の変更・削除は1回の操作
- **左右反転は表示だけ**：データは反転しない。タップした位置のマス座標は、反転を戻してから計算する
- 背景は 0、ビーズは 1..32（M1 の `Sheet`）。消しゴムと削除はどちらも 0 にする
- 自動保存は M2 と同じく 500ms 待ってからまとめて行い、バックグラウンドに移るときとホームに戻るときはすぐ保存する

## Review Focus

1. **指を速く動かしてなぞる**（イベントの間隔があいて、マスが飛び飛びになる）→ 前のマスとの間を `lineCells` で補間し、線が途切れない（Task 3 `stroke interpolates skipped cells`）
2. **シートの外までなぞる、または外でタップする** → 範囲外は無視して落ちない。外から中に入ったところから塗れる（Task 2 `viewToCell returns null outside`、Task 3 `stroke ignores outside points`）
3. **左右反転したまま編集する** → 塗られるのは、見た目で指が触れたマス。データ上は反対側の列（Task 2 `viewToCell mirrors x`、Task 9 の E2E）
4. **ズーム中に 2本指から 1本指に変わる、または 1本指から 2本指に変わる** → 塗りかけのストロークを確定して余計なマスを塗らない。ズームは画面外に飛ばない（Task 4 `clampTransform`、Task 6 の実装規則）
5. **Undo/Redo と自動保存が混ざる**（Undo した直後にホームへ戻る、Redo の途中で保存されるなど）→ 保存されるのは常に画面に見えている状態（Task 3 `undo then close saves the undone state`）

### Task 3: 編集ストア

**Files:**
- Create: `src/state/editor.ts`
- Test: `src/state/editor.test.ts`

**Interfaces:**
- Consumes: `ProjectRepo`（`list`/`load`/`save` など）、`History`、`paintCells`、`lineCells`、`rectCells`、`floodFill`、`outline`、`applyChanges`、`createAutosaver`
- Produces:
  ```ts
  type Tool = 'pen' | 'eraser' | 'bucket' | 'select';
  interface EditorState {
    project: Project | null; error: 'open-failed' | null;
    version: number;               // シートを変えるたびに +1（描画のきっかけ）
    tool: Tool; color: number;     // color は 1..32
    selection: ReadonlySet<number>; rangeMode: boolean; range: [Cell, Cell] | null;
    mirror: boolean; melted: boolean;
    canUndo: boolean; canRedo: boolean;
    open(id: string): Promise<void>;
    setTool(t: Tool): void; setColor(i: number): void;
    strokeBegin(c: Cell): void; strokeMove(c: Cell): void; strokeEnd(): void;  // pen/eraser
    bucket(c: Cell): void;
    tapSelect(c: Cell): void;                        // 選択ツール：1マスずつ切り替え（rangeMode のときは範囲の開始）
    rangeMove(c: Cell): void; rangeEnd(): void;     // 範囲選択のドラッグ
    recolorSelection(): void; deleteSelection(): void; clearSelection(): void;
    applyOutline(thickness: 1 | 2): void;           // 今の color で縁取る
    undo(): void; redo(): void;
    toggleMirror(): void; toggleMelted(): void; setRangeMode(on: boolean): void;
    flush(): Promise<void>; close(): Promise<void>;
  }
  export function createEditorStore(repo: ProjectRepo, now?: () => Date, autosaveMs?: number);
  export function editorStore(); export function useEditor<T>(sel: (s: EditorState) => T): T;
  ```
- ルール
  - 変更はすべて「差分を適用 → `History.push` → `version++` → 自動保存の予約」の順で行う
  - ストロークの途中の差分は1つにまとめ、`strokeEnd` で push する（途中も画面には反映する）
  - `strokeMove` は、前のマスとの間を `lineCells` で補間する
  - 範囲外のマス（`null`）は無視する
  - `color` の初期値は、シートで一番多く使われている色。シートが空なら 5018 くろ
  - 選択の操作のあとは選択を解除する

- [ ] **Step 1: テストを書く**（メモリ版リポジトリ、fake timers）
  - `stroke paints and is one undo step`
  - `stroke interpolates skipped cells`（[0,0] → [4,0] で5マス）
  - `stroke ignores outside points`（strokeMove(null) は何もしない）
  - `eraser sets 0`
  - `bucket fills connected region and undo restores`
  - `tapSelect toggles; range select selects rectangle; recolor/delete apply and clear selection; each one undo step`
  - `outline uses current color with thickness`
  - `redo after undo; new edit clears redo`
  - `edits autosave after 500ms`
  - `undo then close saves the undone state`
  - `open of missing project sets error`
  - `initial color is the most used bead`
- [ ] **Step 2〜4** → **Step 5: Commit**（`feat(state): editor store with tools, selection, undo/redo and autosave`）

### Task 4: ズームの計算（iPhone）

**Files:**
- Create: `src/ui/zoom.ts`
- Test: `src/ui/zoom.test.ts`

**Interfaces:**
- Produces:
  - `interface Transform { scale: number; tx: number; ty: number }`（表示 = シート座標 × scale + t）
  - `IDENTITY`
  - `pinch(start: Transform, a0: Pt, b0: Pt, a1: Pt, b1: Pt): Transform`：2本指の中点を固定して拡大・移動する
  - `clampTransform(t: Transform, contentW: number, contentH: number, boxW: number, boxH: number): Transform`
    - scale は 1..8 に収める
    - 拡大していて内容が箱より大きいときは、箱の外に余白が出ないよう t を制限する
    - 内容が箱より小さい軸は中央に寄せる
  - `toContent(t: Transform, p: Pt): Pt`（表示座標 → 拡大前の座標）

- [ ] **Step 1: テストを書く**
  - `pinch keeps the midpoint fixed and doubles scale`
  - `pinch pans with two fingers moving together`
  - `clampTransform limits scale to 1..8 and edges`
  - `toContent inverts the transform`
- [ ] **Step 2〜4** → **Step 5: Commit**（`feat(ui): pinch/pan transform math`）

### Task 6: 編集キャンバス（ジェスチャー）

**Files:**
- Create: `src/ui/editor/EditorCanvas.tsx`

- 箱の大きさは `onLayout` で測り、`sheetLayout` でマスの大きさを決める
- 描画：`<View style={{ transform: [{ translateX }, { translateY }, { scale }] }}>` の中に、`SheetCanvas` と `SelectionOverlay` を入れる（transform の原点は左上 `transformOrigin: 'top left'`）
- タッチは `PanResponder` で受け取る
  - 1本指：`toContent`（表示座標を拡大前の座標に戻す）→ `viewToCell` → ツールごとの操作
    - pen/eraser：`strokeBegin`、`strokeMove`、`strokeEnd`
    - bucket：指を置いたときに `bucket`
    - select：rangeMode がオフなら置いたときに `tapSelect`。オンなら `tapSelect`（範囲の開始）、`rangeMove`、`rangeEnd`
  - 2本指（iPhone のみ）：`pinch` と `clampTransform`。**2本目の指が置かれた時点で、塗りかけのストロークを `strokeEnd` で確定**し、それ以降は指が全部離れるまでツールの操作をしない
  - ダブルタップ（300ms 以内、2本指以外）：ズームを元に戻す（iPhone のみ）
- iPad と Web ではズームしない（Transform は常に IDENTITY）

- [ ] **Step 1: 実装する** → **Step 2: typecheck・lint** → **Step 3: Commit**（`feat(ui): editor canvas with tools and phone pinch/pan`）
