# M3 実機確認リスト（編集画面）

開発用ビルドで確認する（`npx eas-cli@latest build --profile development --platform ios`）。

| # | 確認すること | 期待する結果 | 結果 |
|---|---|---|---|
| 1 | iPhone で 2本指でピンチ・ドラッグ | シートが拡大・移動する。最大 8倍、画面の外に飛ばない | |
| 2 | ペンで塗っている途中に 2本目の指を置く | それまでの線は確定し、ズーム中に余計なマスが塗られない | |
| 3 | iPhone でダブルタップ | ズームが元に戻る | |
| 4 | iPad で 2本指の操作 | シートは動かない（拡大・移動しない） | |
| 5 | 116 マスの作品でペンをすばやく動かす | 線が途切れない。もたつきが気にならない（気になる場合は動画を共有） | |
| 6 | バケツ・選択（タップ・範囲）・色の変更・削除・縁取り | それぞれ1回の Undo で戻る | |
| 7 | 「表示」→ 左右反転 → 左上をタップ | 見た目どおりの位置が塗られる。反転を戻すと右上に塗られている | |
| 8 | 「表示」→ 完成イメージ | 溶けたような見た目になり、ツールは無効になる | |
| 9 | 編集した直後にアプリを強制終了 → 再起動 | 最後の編集が残っている | |
| 10 | パレットを横にスクロール | パレットの行だけが動き、画面全体はスクロールしない | |
| 11 | 「表示」→ 必要なビーズ | 品番ごとの個数が一覧で出る | |
| 12 | ペンを選び、「ペンの太さ」のスライダーを 1 → 7 まで動かして、それぞれなぞる | 表示の「◯マス」と同じ太さの四角で塗られる。指（ペン先）の位置が塗られる場所の中心になる | |

| 14 | 消しゴムに切り替えて太さを変える → ペンに戻す | ペンと消しゴムで太さが別々に覚えられている | |
| 15 | 太いペンで1回なぞって「元に戻す」 | なぞった分がまとめて戻る | |
| 16 | 太さを変えてアプリを完全に終了 → 開き直す | 選んだ太さが残っている | |
| 17 | 左右反転の表示で、太さ 2 や 4 でなぞる | 反転していないときと同じように、指の位置とその右・下が塗られる | |
| 18 | バケツを選び、色を選んで、塗りたい場所を普通にタップ（少し指がずれてもよい） | つながった同じ色の範囲が塗られる。iPhone・iPad の両方で | |
| 19 | 作品を開いた直後（ほかの操作をする前）に、バケツでタップ | 1回目のタップから、タップした場所が塗られる | |
