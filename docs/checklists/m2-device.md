# M2 実機確認リスト（iPhone / iPad）

Expo Go で確認する。手順は `docs/testing/device-testing.md` を参照。

| # | 確認すること | 期待する結果 | 結果 |
|---|---|---|---|
| 1 | ホーム →「＋ 新しく作る」→「写真から作る」→「写真ライブラリから選ぶ」で写真を選ぶ | ② 下ごしらえの画面に、選んだ写真と切り抜き枠が表示される | |
| 2 | 切り抜き枠の4隅・中をドラッグする | 枠が写真の外に出ない。最小 8px より小さくならない | |
| 3 | 明るさ・コントラストのスライダーを動かす | 写真の見た目がすぐ変わる | |
| 4 | 「次へ」→ ③ ビーズ化 | プレビューが表示され、「使用 N色 ・ M粒」が出る | |
| 5 | サイズ 116 を選び、プレビューが出るまでの時間を測る | **目標 2秒以内**（実測値を右欄に記入） | |
| 6 | 4800万画素（ProRAW 以外の HEIC/JPEG）の写真を選ぶ | 落ちずに ② が表示される | |
| 7 | ③ の途中でアプリを上にスワイプして強制終了 → 再起動 | ホームに「作成中」のカードがあり、タップすると ③ に戻る。設定が保たれている | |
| 8 | ③ で「完了」 | 作品画面にシートと必要なビーズが表示される | |
| 9 | 設定アプリで写真へのアクセスを「なし」にして「写真から作る」 | 「写真を読み込めませんでした」の案内が出る（落ちない） | |
| 10 | カードを長押し → 名前を変更 / 複製 / 削除 | それぞれ一覧に反映される。削除は確認が出る | |
| 11 | iPhone（縦）と iPad（縦・横）で各画面を開く | どの画面も全体がスクロールしない（作品一覧の中のスクロールは可） | |
| 12 | 「白紙から作る」→ サイズを選ぶ | 空のシートの作品画面が開く | |
| 13 | 「写真から作る」→「ファイルから選ぶ」→「ファイル」アプリ（iCloud Drive など）の画像を選ぶ | ② 下ごしらえに選んだ画像が表示される | |
| 14 | 「ファイルから選ぶ」で PDF を選ぶ（2ページ以上のものも） | ② 下ごしらえに PDF の1ページ目が表示される | OK（PDF から作れることを確認） |
| 15 | ② 下ごしらえで「作品名」をタップし、日本語（例：ねこの顔）に変えて「次へ」→「完了」 | 変換の途中で入力が消えない。ホームと書き出しのファイル名が新しい名前になる | |
| 16 | 「作品名」を全部消して、ほかの場所をタップ | 元の名前に戻る | |
| 17 | ③ ビーズ化を開く | 「使うビーズ」が「元の色」で、プレビューが写真の色のまま（ビーズの色に変わっていない）。上に「元の色で表示中」と出る | |
| 18 | 「元の色」のまま「完了」 | 「どのビーズで作りますか？」と聞かれ、選んだ色で作品ができる。キャンセルすると何も起きない | |
| 19 | 「…」→「手持ち」 | 下から画面いっぱいに出る（ビーズシートは見えない）。64色が番号順（今までと同じ並び）で、色の名前が上・品番が下。最初はすべて未選択 | |
| 20 | 手持ちで、指で横になぞる／タップ／縦にスクロール | 横になぞった色がまとめて選ばれる（選択済みから始めると外れる）。タップで1色ずつ切り替わる。縦に動かすとスクロールして、色は変わらない | |
| 21 | 「この画像に合う色」「8色を入れる」「すべて外す」、色の名前・品番で検索（例：あか、5005） | それぞれ一度で選ばれる／外れる。検索に合わない色が薄くなる | |
| 22 | 手持ちを選んでからアプリを完全に終了 → 別の写真で③を開いて「…」→「手持ち」 | 前に選んだ手持ちが残っている（作品ごとではなく共通） | |
| 23 | 前に作った作品・.beads ファイルを開く | 今までどおり開ける。色も変わらない | |
| 24 | 「用途」を「写真」にする | 「ディザリング」の設定が出ない（なくした） | |
