# M2 実機確認リスト（iPhone / iPad）

開発用ビルドで確認する（Expo Go には Skia などのネイティブモジュールが入っていないため使えない）。

```bash
npx eas-cli@latest build --profile development --platform ios
```

| # | 確認すること | 期待する結果 | 結果 |
|---|---|---|---|
| 1 | ホーム →「＋ 新しく作る」→「写真から作る」で写真を選ぶ | ② 下ごしらえの画面に、選んだ写真と切り抜き枠が表示される | |
| 2 | 切り抜き枠の4隅・中をドラッグする | 枠が写真の外に出ない。最小 8px より小さくならない | |
| 3 | 明るさ・コントラストのスライダーを動かす | 写真の見た目がすぐ変わる | |
| 4 | 「次へ」→ ③ ビーズ化 | プレビューが表示され、「使用 N色 ・ M粒」が出る | |
| 5 | サイズ 116 を選び、プレビューが出るまでの時間を測る | **目標 2秒以内**（実測値を右欄に記入） | |
| 6 | 4800万画素（ProRAW 以外の HEIC/JPEG）の写真を選ぶ | 落ちずに ② が表示される | |
| 7 | ③ の途中でアプリを上にスワイプして強制終了 → 再起動 | ホームに「作成中」のカードがあり、タップすると ③ に戻る。設定が保たれている | |
| 8 | ③ で「完了」 | 作品画面にシートと必要なビーズが表示される | |
| 9 | 設定アプリで写真へのアクセスを「なし」にして「写真から作る」 | 「写真を読み込めませんでした」の案内が出る（落ちない） | |
| 10 | カードを長押し → 名前を変更 / 複製 / 削除 | それぞれ一覧に反映される。削除は確認が出る | |
| 11 | iPhone（縦）と iPad（縦・横）で各画面を開く | どの画面も全体がスクロールしない（作品一覧の中のスクロールは可） | |
| 12 | 「白紙から作る」→ サイズを選ぶ | 空のシートの作品画面が開く | |
