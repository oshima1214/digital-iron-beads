# 実機確認リスト：画面の名前・作品名・書き出し・作り直し（2026年11月19日の変更）

Expo Go で確認する。手順は `docs/testing/device-testing.md`。

この変更で、M5 の確認リストの 2（左右反転のスイッチ）と 9（必要なビーズをテキストで共有）はなくなった。

| # | 確認すること | 期待する結果 | 結果 |
|---|---|---|---|
| 1 | 写真から作る → 写真を選ぶ | 画面の名前が「画像切り出し」、右上が「シート作成」。作品名の欄は空（「名前を入れてください」と薄く出る） | |
| 2 | 作品名を空のまま「シート作成」 | 「作品名を決めてください」と出て、先に進まない。作品名の欄に入力できる状態になる | |
| 3 | 作品名を入れて「シート作成」 | 「ビーズシート作成」画面が開く。右上が「編集」 | |
| 4 | 「編集」 | 編集画面が開く。上の数が「◯色 ・ ◯ビーズ」 | |
| 5 | 編集画面の右上 | 「表示」ではなく「メニュー」 | |
| 6 | メニュー → 必要なビーズ | 色の名前が太字、品番はかっこで小さく、数は「◯ビーズ」 | |
| 7 | メニュー → ビーズシートを作り直す → 「作り直す」 | 「ビーズシート作成」画面が開き、前の設定が入っている | |
| 8 | 7 でサイズを変えて「編集」 | 同じ作品の編集画面に戻り、新しいサイズのシートになっている（作品は増えない） | |
| 9 | 7 で「‹ 戻る」 | 編集画面に戻り、シートは前のまま | |
| 10 | 文字・白紙から作った作品のメニュー | 「ビーズシートを作り直す」が出ない | |
| 11 | メニュー → 書き出し・共有 | 一番上に作品名の欄。ボタンはすべて同じ見た目（青いボタンがない）。左右反転のスイッチと「テキストで共有」がない | |
| 12 | 書き出し・共有で作品名を変えて「画像（PNG）で共有」→「画像を保存」 | 写真アプリの画像に、ビーズシートと、その下に必要なビーズの一覧（色の丸・色名（品番）・数・合計）がある。ファイル名が新しい作品名 | |
| 13 | 12 のあと「‹ 戻る」→ ホーム | 編集画面とホームの作品名が新しい名前になっている | |
| 14 | 切り抜いて作った作品を「.beads で共有」→「ファイル」に保存 → 拡張子を .zip にして開く | `source.png` が切り抜いた部分だけの画像になっている | |
| 15 | 写真から作った作品の .beads を、ホームの「読み込み」で開く | 編集画面で開く。メニューに「ビーズシートを作り直す」があり、作り直せる | |
| 16 | 型紙を印刷 / PDF | 一覧が「色の名前（品番）◯ビーズ」 | |
| 17 | 制作ナビで最後のプレートの最後の色まで「次へ」 | 「すべて完成！」と「ホームへ」ボタンが出て、押すとホームに戻る | |
| 18 | ビーズシート作成の「2色」、文字から作るの文字の色・背景 | 「色の名前（品番）」の形で出る | |
