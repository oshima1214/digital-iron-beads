# M4 実機確認リスト（プレート・制作ナビ・iPad 実寸）

開発用ビルドで確認する（`npx eas-cli@latest build --profile development --platform ios`）。

| # | 確認すること | 期待する結果 | 結果 |
|---|---|---|---|
| 1 | iPad で 設定 → 実寸の調整。定規（100mm）に実物の定規を当てる | 誤差 ±1mm 以内（ずれていたら −/＋ で合わせる） | |
| 2 | 実物のプレートの端の1列を、29個の点に重ねる | 穴と点がそろう（端から端まで） | |
| 3 | 制作ナビで実物のプレートを画面に置く | 今の色の丸が穴の真下にある。端のずれが ±1mm 以内 | |
| 4 | プレートを置いたまま画面に触れる・手をつく | ナビの状態が変わらない（シート領域はタッチ無効） | |
| 5 | iPad 縦向き / 横向き | 縦はパネルが上・シートが下、横は左右（設定で左右を入れ替え） | |
| 6 | iPad mini（縦向き） | 「横向きにしてください」と出る | |
| 7 | iPad mini（横向き） | 上半分 / 下半分 の切り替えが出て、それぞれ実寸で表示される | |
| 8 | 58 / 116 の作品でミニマップのプレートを切り替える（編集・ナビ） | 選んだプレートが表示される | |
| 9 | ナビの途中でアプリを強制終了 → 再起動 → 作品 → ナビ | 同じプレート・同じ色から再開する | |
| 10 | 表にない新しい iPad（あれば） | 初めてナビを開くと「大きさを調整してください」が出る | |
