# タイトル画面の絵

起動したときのタイトル画面（`src/ui/TitleScreen.tsx`）で使う、ビーズの絵です。

| ファイル | もとの絵 | 大きさ |
|---|---|---|
| `wave.png` | 葛飾北斎「冨嶽三十六景 神奈川沖浪裏」 | 72×51 マス |
| `fuji.png` | 葛飾北斎「冨嶽三十六景 凱風快晴」 | 72×48 マス |
| `beads-illust.png` | ビーズのイラスト（持ち主から受け取った画像） | 400×400 px |

アプリ名の文字は Google Fonts の「Mochiy Pop One」（`@expo-google-fonts/mochiy-pop-one`、SIL Open Font License）。

## 作り方

アプリと同じ変換（`src/core/convert`、用途「写真」、64色）でビーズにして、ビーズを丸く描いています。背景は透明です。

1. もとの画像の鮮やかさを上げる（スキャンの色があせていて、そのままだと藍色が灰色のビーズになるため）
   - 神奈川沖浪裏：鮮やかさ ×2.2、コントラスト ×1.15
   - 凱風快晴：鮮やかさ ×1.3、コントラスト ×1.1
2. 変換して描く

```bash
npm run title:beads -- <入力画像> assets/title/wave.png 72 photo
```

## 権利について

北斎の作品そのものは著作権が切れています（パブリックドメイン）。
今の絵は、持ち主から受け取った画像から作りました。ビーズのイラストが素材サイトのものなら、その利用規約（アプリでの使い方の条件）を確認すること。App Store に出す前に、美術館が自由に使ってよいとして公開している画像（パブリックドメイン・CC0 など）から作り直すと安心です。
